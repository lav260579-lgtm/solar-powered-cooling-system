# solar-powered-cooling-system
Introduction 
The solar powered cooling system is a project designed to utilize solar energy to operate a cooling mechanism. It aims to provide an energy efficient and environmentally friendly cooling solution.
Objectives 
- To utilize renewable solar energy.
- To reduce dependence on conventional electricity.
- To develop an efficient cooling system.
- To promote sustainable technology.
Components required
- Arduino Uno
- Temperature Sensor
- Humidity Sensor
- OLED Display
- Solar Panel
- Female and Male Jumper Wires
- Battery
- Charge Controller
- Peltier Cooling System
- Relay module (Cooling Fan/Heat Sink)
Working principle
Hardware design
Applications
- Small cooling systems
- renewable energy based cooling applications
- energy efficient cooling solutions.
  Future scope
The system can be improved through better energy management, temperature monitoring and automation.
