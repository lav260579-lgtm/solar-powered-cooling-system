# solar-powered-cooling-system
# Introduction 
The solar powered cooling system is a project designed to utilize solar energy to operate a cooling mechanism. It aims to provide an energy efficient and environmentally friendly cooling solution.
# Objectives 
- To utilize renewable solar energy.
- To reduce dependence on conventional electricity.
- To develop an efficient cooling system.
- To promote sustainable technology.
# Components required
- Arduino Uno
- Temperature Sensor
- Humidity Sensor
- OLED Display
- Solar Panel
- Female and Male Jumper Wires
- Battery
- Charge Controller
- Peltier Cooling System
- Relay module (Cooling Fan/Heat Sink)

# Working principle

The solar panel generates electrical energy, which is regulated by the charge controller and stored in a 12V battery. The stored energy powers the cooling system and control electronics.
The Arduino Uno receives temperature and humidity readings from the DHT22 sensor. These readings can be displayed on the LCD. The cooling mechanism and fans help maintain the required storage conditions.
